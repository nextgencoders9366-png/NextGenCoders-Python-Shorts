# Background Removal using Python

A simple Python project that removes the background from an image using the `rembg` library.

## Technologies Used

- Python
- rembg
- Jupyter Notebook
- PIL (Pillow)

## How It Works

The project takes an input image and uses the `rembg` library to automatically remove its background.

## Project Files

- `background_removal.ipynb` — Python/Jupyter Notebook containing the code
- `input image` — Image used for background removal
- `output image` — Image with the background removed
