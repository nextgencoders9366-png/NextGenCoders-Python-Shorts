# OpenCV Image Processing

A beginner-friendly Python project demonstrating basic image processing using OpenCV.

## Technologies Used

- Python
- OpenCV
- Matplotlib
- Jupyter Notebook

## What This Project Covers

- Reading images using OpenCV
- Displaying images
- Converting images to grayscale
- Basic image processing
- Visualizing images using Matplotlib

## Project Files

- `cv_project.ipynb` – Jupyter Notebook containing the code
- `cv_project.jpeg` – Sample image used in the project
